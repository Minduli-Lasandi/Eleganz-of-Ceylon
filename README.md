# Eleganz of Ceylon

> *A place where unforgettable memories await.*

A collaborative tourism website dedicated to showcasing the beauty, culture, wildlife, and adventures of Sri Lanka. Built as a group university project.

---

##  Live Site

Link: https://Minduli-Lasandi.github.io/Eleganz-of-Ceylon/

##  Deployment

This site is deployed using **GitHub Pages** with no build step required. The root `index.html` acts as an entry point and redirects to the main landing page.
